# Breadboard Battler

Circuit-based roguelite auto battler for mobile.

## Core idea

Build a combat system on a limited breadboard, then let the completed circuit fight automatically.

- Limited board space is a primary resource.
- Weapons and support modules require suitable voltage/current.
- Batteries provide stored energy.
- Capacitors provide short high-current bursts.
- Electrically equivalent layouts should behave equivalently even when their shapes differ.
- Beginner-friendly recommended circuits provide a baseline; experienced players can rearrange and optimize them.
- Combat rewards feed a shop loop where new weapons, circuit parts, board expansion, and power upgrades are purchased.
